## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

# 🏁 PitCrew AI – Work Like a Formula 1 Team

PitCrew AI is an Atlassian Forge app that transforms Jira sprints into a Formula 1–style race operation. Powered by Rovo agents, it helps teams detect blockers early, take corrective action fast, and continuously improve sprint performance.

## 🚀 What It Does

- Live sprint health monitoring
- AI-powered recommendations via Rovo
- One-click Jira actions
- Automated Confluence sprint debriefs

## 🧠 Why It Matters

High-performing teams don’t just react — they anticipate. PitCrew AI gives teams the clarity and speed of an F1 pit wall, directly inside Atlassian tools.

## 🛠 Built With

- Atlassian Forge
- Jira Software APIs
- Confluence APIs
- Rovo Agent & Action Modules

## 🏎 Inspired By

Williams Racing and the philosophy of precision, speed, and continuous optimization.
